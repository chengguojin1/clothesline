# Security

Jemur runs locally (it only goes online for update checks and for previews of web addresses written in notes) and stores data only in `%APPDATA%\Jemur` and `%LOCALAPPDATA%\Jemur`.

If you find a security problem, please don't open a public issue. Use GitHub's [private vulnerability reporting](https://github.com/revanapriyandi/jemur/security/advisories/new) instead, and I'll reply as soon as I can.
